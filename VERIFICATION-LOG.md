# Verification Log

Record how you used AI assistance on this assignment, and how you checked the
result. Submitting work you have not verified is the thing this log exists to
catch.

Leave a section empty only if it genuinely does not apply.

## 1. Tools used

List each AI tool you used (ChatGPT, Copilot, Claude, none, …) and roughly
what you used it for.

## 2. What you asked, and what you got

For each substantive prompt, note what you asked and what came back. You do
not need to paste full transcripts — a sentence each is enough.

-

## 3. How you verified it

For every piece of AI-generated code you kept: how do you know it is correct?
"The tests passed" is a legitimate answer. So is "I traced it by hand on the
tie case." "It looked right" is not.

-

## 4. What you rejected or changed

Anything the tool suggested that was wrong, or that you rewrote. This section
is often the most informative one — a log with nothing here usually means the
work was not read closely.
